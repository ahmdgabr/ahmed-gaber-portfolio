## Featured project — Advanced Sales Data Cleaning & Analysis

An end-to-end Excel case study demonstrating practical data preparation, data-quality handling, validation, and dashboard reporting.

- Reviewed 6,080 source records and prepared 6,000 records.
- Removed 80 duplicate rows; no duplicates remained in the prepared dataset.
- Reconciled sales (48,768,795) and profit (11,786,913.5) across published analytical outputs.
- Built a two-page Excel dashboard.
- Published anonymized source data and a cleaned dataset for review.
